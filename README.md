# 移动校园模拟 · Mobile Campus Simulation

> EZeroStudio（E零工作室）项目 · 聊城大学东昌学院

---

## 项目简介

本项目模拟了一个移动端校园请假申请表单页面，完整还原了移动端表单的交互体验，包括学生信息填写、请假信息录入、审批流程展示等模块。页面以手机框架（Phone Frame）形式呈现，适用于原型展示与教学演示。

---

## 功能特性

- **学生信息填写** — 学号、姓名、性别、班级、专业、入学时间等字段
- **请假信息录入** — 请假类型（事假/病假）、时间范围、天数、交通工具、事由说明
- **审批流程表格** — 任务节点、开始/结束时间、执行人、审批意见与状态
- **编辑模式** — 一键开启，全文皆可直接编辑
- **导出图片** — 将表单保存为高清 PNG 图片
- **水印开关** — 支持激活后隐藏水印
- **复制数据** — 将表单内容复制为 JSON

## 使用说明

### 启用编辑模式

页面底部有**启用编辑模式**复选框，勾选后所有标注为可编辑的区域（带有 `data-editable` 属性）均可直接点击修改文字内容。

### 保存为图片

点击底部**保存图片**按钮，将当前表单以 3 倍分辨率导出为 PNG 文件，文件名格式为 `leave-YYYYMMDD-HHmmss.png`。

### 水印控制

点击**关闭水印**按钮，输入激活码 `qy520521` 即可隐藏页面水印。

### 复制表单数据

点击底部**复制**按钮（需在编辑模式下），将表单数据以 JSON 格式复制到剪贴板。
